# 空间数据与自动采集路线

Roomark 当前使用模拟空间记录和户型图简化几何，帮助用户保存房间尺寸语义并进入 3D 软装流程。它不宣称已经实现自动空间扫描。

## 当前数据来源

- `mock`：应用生成的稳定样例空间
- `floorplan`：根据用户选择的户型图宽高比生成的简化空间

两种来源都必须保留来源字段、生成时间和正数尺寸，并通过相同的持久化校验。

## 未来自动采集

支持深度传感器的设备可以在未来接入原生空间采集能力。接入时必须继续使用相同的 `RoomMesh` 语义，并补齐：

- 物理设备权限和兼容性检查
- 采集失败恢复
- 尺寸精度基准
- 模型文件存储与隐私说明
- 长时间运行的内存和温度验证

自动采集不应被描述为专业测绘。Roomark 的目标是租住决策支持、家具适配估算和现场记录，而不是替代工程测量。
