# Changelog

All notable changes to Roomark are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses semantic versioning for public releases.

## [Unreleased]

### Added

- Public repository content policy
- Bilingual product documentation and open-source governance

### Changed

- Repository structure now focuses on the maintained Android, browser, website, and backend surfaces
- User-facing copy now describes simulated spatial data and concept effects truthfully

### Removed

- Historical collateral, obsolete prompts, redundant applications, and empty future-feature placeholders

## [0.1.0] - 2026-07-27

### Added

- Android local-first property library, comparison, map, simulated spatial record, 3D furnishing, and concept-effect state
- Recovery for corrupt local state and retryable persistence failures
- Android 14 emulator verification and standalone release APK
